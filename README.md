# 🚀 User Management API

## 📌 Description
This is a User Management API built using Node.js, Express, and MongoDB.  
It allows users to register, login, and manage their profile with secure authentication using JWT.

---

## 🔥 Features
- User Registration
- User Login (JWT Authentication)
- Password Hashing (bcrypt)
- Protected Routes
- Change Password

---

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB
- JWT (Authentication)
- bcrypt (Security)

---

## 📂 API Endpoints

### 🔹 Register User
POST /api/auth/register

### 🔹 Login User
POST /api/auth/login

### 🔹 Get Profile
GET /api/auth/me

---

## ▶️ Run Locally

```bash
npm install
npm start
```
